# Al Bayan AI ওয়েবসাইট বানানো আর Google-এ আনার পুরো নিয়ম

নির্মাতা: আদনান (Adnan)

এই কাজটা **কম্পিউটারে** করা সবচেয়ে সহজ। ফোন দিয়ে ফোল্ডারসহ ফাইল আপলোড করা কঠিন।
মোট সময় লাগবে প্রায় ৩০–৪৫ মিনিট।

---

## তোমার যা লাগবে

| জিনিস | খরচ |
|---|---|
| GitHub অ্যাকাউন্ট | ফ্রি |
| Vercel অ্যাকাউন্ট (ওয়েবসাইট চালানোর জায়গা) | ফ্রি |
| Upstash Redis (সীমা, প্ল্যান, কোড মনে রাখার ডেটাবেস) | ফ্রি প্ল্যানই যথেষ্ট |
| Anthropic API key (Al Bayan AI-র উত্তর দেওয়ার জন্য) | যত ব্যবহার তত খরচ, ৫ ডলার দিয়ে শুরু করা যায় |
| নিজের ডোমেইন, যেমন lumina.com.bd (ঐচ্ছিক) | বছরে ~১০০০–১৫০০ টাকা |

## ধাপ ১: ফাইলগুলো GitHub-এ রাখো

1. zip ফাইলটা কম্পিউটারে **Extract** করো। একটা ফোল্ডার পাবে।
2. **github.com**-এ অ্যাকাউন্ট খোলো।
3. ওপরে ডানদিকে **+** → **New repository**। নাম দাও `lumina`, **Private** বেছে নাও, তারপর **Create repository**।
4. **uploading an existing file** লিংকে চাপো।
5. Extract করা ফোল্ডারের **ভেতরের সব কিছু** (`index.html`, `admin.html`, `api`, `lib`, `data` ফোল্ডারসহ) টেনে এনে ছেড়ে দাও।
6. নিচে **Commit changes** চাপো।

## ধাপ ২: Anthropic API key নাও

1. **console.anthropic.com**-এ অ্যাকাউন্ট খোলো।
2. **Billing** → কার্ড দিয়ে কিছু ক্রেডিট কেনো (যেমন ৫ ডলার)।
3. **Limits**-এ গিয়ে মাসিক খরচের একটা সীমা বেঁধে দাও, যাতে হঠাৎ বেশি টাকা না কাটে।
4. **API Keys** → **Create Key** → key-টা কপি করে কোথাও লুকিয়ে রাখো। কাউকে দেখাবে না।

## ধাপ ৩: Vercel-এ ওয়েবসাইট চালু করো

1. **vercel.com** → **Sign up with GitHub**।
2. **Add New → Project** → `lumina` রিপোজিটরির পাশে **Import**।
3. **Environment Variables** অংশে এই দুটো যোগ করো:
   - `ANTHROPIC_API_KEY` = ধাপ ২-এর key
   - `SUPER_ADMIN_KEY` = তোমার নিজের বানানো একটা লম্বা গোপন পাসওয়ার্ড (কমপক্ষে ১২ অক্ষর, যেমন `Adnan-Al Bayan AI-2026-xyz!`)। এটা দিয়েই তুমি **সুপার অ্যাডমিন** হবে।
4. **Deploy** চাপো। ১–২ মিনিট পর একটা লিংক পাবে, যেমন `lumina-xxxx.vercel.app`। এটাই তোমার ওয়েবসাইট!

## ধাপ ৪: ডেটাবেস যুক্ত করো (জরুরি)

এটা না করলে সীমা গোনা, প্ল্যান, কোড আর অ্যাডমিন ঠিকমতো মনে থাকবে না।

1. Vercel-এ তোমার প্রজেক্ট → ওপরে **Storage** ট্যাব।
2. **Create Database** → **Upstash for Redis** (Marketplace) → ফ্রি প্ল্যান → **Create**।
3. প্রজেক্টের সাথে **Connect** করো। Vercel নিজে থেকে `KV_REST_API_URL` আর `KV_REST_API_TOKEN` বসিয়ে দেবে।
4. **Deployments** ট্যাব → সবচেয়ে ওপরের ডিপ্লয়ের পাশে **⋯** → **Redeploy**।

## ধাপ ৫: সুপার অ্যাডমিন হিসেবে ঢোকো

1. `তোমার-ওয়েবসাইট/admin.html` খোলো, যেমন `lumina-xxxx.vercel.app/admin.html`।
2. `SUPER_ADMIN_KEY` দিয়ে লগইন করো।
3. এখান থেকে যা করতে পারবে:
   - **অ্যাডমিন বানানো/সরানো:** প্রতিটা অ্যাডমিনের জন্য আলাদা কী তৈরি হয়। কী শুধু একবার দেখায়, তখনই কপি করে নাও।
   - **অ্যাক্টিভেশন কোড বানানো:** Go/Plus/Pro, কত দিনের জন্য।
   - **কাউকে সরাসরি প্ল্যান দেওয়া:** ব্যবহারকারীর "আইডি" দিয়ে। আইডিটা সে Al Bayan AI-র প্ল্যান পাতায় দেখতে পায়।
   - **প্ল্যানের নাম, দাম, সীমা বদলানো** (−1 মানে সীমাহীন), রিসেটের সময় বদলানো।
   - **bKash নম্বর আর যোগাযোগের তথ্য** বসানো। এগুলো প্ল্যান পাতায় দেখাবে।
4. অ্যাডমিন প্যানেলে লগইন করলে **সেই ব্রাউজারে Al Bayan AI তোমার জন্য সীমাহীন** হয়ে যায়। Al Bayan AI-র ⚡ বোতাম → "অ্যাডমিন লগইন" দিয়েও করা যায়।

**অ্যাডমিন আর সুপার অ্যাডমিনের পার্থক্য:**
- অ্যাডমিন কোড বানাতে, প্ল্যান দিতে আর সীমাহীন ব্যবহার করতে পারে।
- সুপার অ্যাডমিন এর সাথে অ্যাডমিন বানাতে/সরাতে আর দাম ও সীমা বদলাতেও পারে।

## ধাপ ৬: টাকা নেওয়ার নিয়ম (এখনকার ব্যবস্থা)

1. কেউ প্ল্যান পাতায় "Plus নাও" চাপলে তোমার bKash/Nagad নম্বর দেখবে।
2. সে টাকা পাঠিয়ে Transaction ID তোমাকে মেসেজ করবে।
3. তুমি bKash অ্যাপে টাকা এসেছে কিনা দেখে নেবে। তারপর অ্যাডমিন প্যানেল থেকে একটা কোড বানিয়ে তাকে দেবে। অথবা তার আইডি দিয়ে সরাসরি প্ল্যান দিয়ে দেবে।
4. সে কোড বসালেই প্ল্যান চালু হয়ে যাবে।

পরে স্বয়ংক্রিয় পেমেন্ট (SSLCommerz, bKash Payment Gateway) যোগ করতে চাইলে মার্চেন্ট অ্যাকাউন্ট লাগবে।

## ধাপ ৭: নিজের ডোমেইন (ঐচ্ছিক, তবে Google-এর জন্য ভালো)

1. Namecheap, GoDaddy বা বাংলাদেশি কোনো বিক্রেতার কাছ থেকে ডোমেইন কেনো।
2. Vercel প্রজেক্ট → **Settings → Domains** → ডোমেইনটা লেখো → **Add**।
3. Vercel যে DNS রেকর্ড দেখাবে (A বা CNAME), সেটা ডোমেইন বিক্রেতার ওয়েবসাইটে বসাও। কয়েক মিনিট থেকে কয়েক ঘণ্টা লাগতে পারে।

## ধাপ ৮: Google-এ পাবলিশ করো

1. GitHub-এ `sitemap.xml` ফাইল খোলো → ✏️ চাপো → `YOUR-DOMAIN` এর জায়গায় তোমার আসল ঠিকানা বসাও → **Commit**। Vercel নিজে থেকে নতুন করে চালু হবে।
2. **search.google.com/search-console** → **Add property** → **URL prefix** → তোমার ঠিকানা লেখো।
3. মালিকানা যাচাই: **HTML tag** পদ্ধতি বেছে নাও। Google একটা `<meta name="google-site-verification" ...>` লাইন দেবে।
4. GitHub-এ `index.html` খোলো → ✏️ → `<meta name="author" content="Adnan">` লাইনের ঠিক নিচে লাইনটা পেস্ট করো → **Commit**। এক মিনিট পর Search Console-এ **Verify** চাপো।
5. বাঁদিকে **Sitemaps** → `sitemap.xml` লিখে **Submit**।
6. ওপরের সার্চ বক্সে তোমার ঠিকানা লিখে → **Request Indexing**।
7. সাধারণত কয়েক দিন থেকে কয়েক সপ্তাহের মধ্যে Google-এ "Al Bayan AI কুরআন হাদিস আরবি" লিখে খুঁজলে তোমার ওয়েবসাইট আসা শুরু করবে।

**আরও তাড়াতাড়ি খুঁজে পেতে:** ফেসবুক পেজ, গ্রুপ আর YouTube-এ ওয়েবসাইটের লিংক শেয়ার করো। অন্য জায়গা থেকে যত বেশি লিংক আসে, Google তত তাড়াতাড়ি আর ওপরে দেখায়।

## ফাইলগুলো কী কাজ করে

- `index.html`: পুরো ওয়েবসাইট
- `admin.html`: অ্যাডমিন প্যানেল (Google-এ দেখাবে না)
- `api/chat.js`: প্রশ্নের উত্তর, ডিজাইন, সীমা যাচাই
- `api/usage.js`, `api/redeem.js`, `api/admin.js`: ব্যবহারের হিসাব, কোড চালু, অ্যাডমিন কাজ
- `lib/plans.js`: প্ল্যান, দাম, সীমার শুরুর মান (অ্যাডমিন প্যানেল থেকেও বদলানো যায়)
- `lib/account.js`, `lib/store.js`: অ্যাকাউন্ট আর ডেটাবেস
- `lib/chem.js`: রসায়নের হিসাব
- `lib/katex`: গণিতের সূত্র সুন্দর করে দেখানোর ফন্ট
- `data/`: সূরা আর হাদিসের তালিকা

**ডেটা কোথা থেকে আসে:** কুরআন, তাফসীর আর হাদিসের পুরো লেখা ওয়েবসাইট নিজেই jsDelivr দিয়ে নিয়ে আসে, তাই আপলোড করতে হয় না।
- কুরআন (আরবি, বাংলা, ইংরেজি): quran-json, CC BY 4.0
- তাফসীর ইবনে কাসীর (তাওহীদ পাবলিকেশন্স), আবু বকর যাকারিয়া, আহসানুল বায়ান: Quranic Universal Library (Tarteel) / quran.com, spa5k/tafsir_api দিয়ে
- হাদিস: fawazahmed0/hadith-api। বাংলা অনুবাদ hadithbd.com-এর, হাদিসের মান আলবানী প্রমুখের।

## খরচ নিয়ে সতর্কতা

- প্রতিটা প্রশ্নের উত্তরে Anthropic-এ সামান্য খরচ হয়। ছবি বা বড় PDF পাঠালে আর ধাপে ধাপে গণিত সমাধানে একটু বেশি খরচ হয়।
- ফ্রি ব্যবহারকারীরা প্রতি ৪ ঘণ্টায় ১০টা প্রশ্ন করতে পারে। একই ইন্টারনেট সংযোগ (IP) থেকে ফ্রিতে তার ৬ গুণের বেশি ব্যবহার করা যায় না।
- অ্যাডমিনদের কোনো সীমা নেই, তাই অ্যাডমিন কী শুধু বিশ্বস্ত মানুষকে দাও।
- Anthropic কনসোলে মাসিক খরচের সীমা অবশ্যই বেঁধে রাখো।
